Каналы: блок «Cookie кабинетов» Что делает: • подключает FunPay, ZeusX и Eldorado к Ledger • показывает балансы, заказы/продажи и лоты • импортирует новые заказы во вкладку «Заказы» • включает Always online для каждого канала Как работает: 1. Вставьте cookie/токен в поля 2. Нажмите «Сохранить cookie» 3. Ledger опрашивает кабинеты не чаще раза в 2 минуты 4. Статус показывает: есть / нет / ошибка / последняя проверка Что вставлять: • FunPay — golden_key • ZeusX — access_token • Eldorado — Client ID + Client Secret (Seller API) Cookie хранятся только на сервере. Никому не передавайте; если истекли — обновите. Free desktop · Ledger+ from $7/mo github.com/voidwhisperr/ledger
