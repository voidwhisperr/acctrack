# Ledger 1.66.41 — безпека, яка працює

Ledger 1.66.41 — оновлення безпеки й надійності для безкоштовного десктопного застосунку та хостингової версії Ledger+.

## Що змінилось

- **2FA + підтвердження:** зміна пароля й 2FA тепер вимагає поточного пароля та одноразового коду.
- **Відновлення через пошту:** забув пароль — код на 10 хвилин приходить на резервну пошту.
- **Ізольований підпис ліцензій:** ключ підпису зберігається на окремому хості, а не на веб-сервері.
- **Шифровані offsite-бекапи:** зашифровані копії йдуть у Cloudflare R2 і на твій ПК.

Дані й налаштування залишаються на місці.
