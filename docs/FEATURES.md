# Що працює, а що ні

Головне правило: **AccTrack працює повністю вручну без жодного токена.**
Токени лише додають автоматику — вони не «вмикають» застосунок.

## Чому щось «не працює»

**Каталог порожній.** Товари тягнуться з Shopify-магазинів (`/products.json`).
Поки не додано жодного постачальника — показує «Ще немає постачальників».
Додати: `⚙ → Мій постачальник (Shopify)` → назва + `https://shop.example.com`.

**План «Що купити» порожній.** Він рахує медіану ваших продажів по схожих лотах
і порівнює з ціною постачальника. Немає історії продажів або каталогу → немає що порівнювати.

**FunPay/ZeusX показують «не підключено».** Це не помилка — просто немає токена.
Вставте токен у `⚙ → Підключення` (або в Каналах), і картка оживе.

**Taobao недоступний.** Taobao блокує серверні IP і вимагає капчу.
Це окремий агент (Playwright + браузер на вашому ПК) — він не входить у цей репозиторій.
Потрібна автоматизація — Telegram **@ENOUGHT285**, email **dhdueu564@gmail.com**, Discord **facemyfear**.

**Замовлення з пошти не приходять.** Потрібен Gmail із **App Password**
(Google → Security → 2-Step → App passwords), звичайний пароль не підійде.

**Eldorado «не тягне» дані.** У Eldorado немає публічного API — тільки ручний облік
або листи пошти. Це обмеження майданчика, не застосунку.

**Каталог не оновлюється сам.** Оновлення раз на 6 год; кнопка `↻ Оновити зараз` —
примусове. Якщо «⏳ оновлюю…» висить довго — це нормально (5–6 хв на 2000 товарів).

## Що потрібно для постійної роботи

| Варіант | Плюси | Мінуси |
|---|---|---|
| **ПК (Windows)** | безкоштовно, дані локально | працює лише коли ПК увімкнений |
| **VPS $5–6/міс** | 24/7, доступ з телефона | треба раз налаштувати |
| **Docker** | `docker compose up -d` | потрібен Docker |

Деталі — `docs/SETUP.md`.

## Безпека

- Пароль входу генерується випадковий при першому запуску (`.gt_secrets.json`, права 600).
- Токени й cookie зберігаються лише на вашому сервері/ПК, **не передаються третім сторонам**.
- Дані акаунтів на складі зберігаються у файлі — робіть бекапи.
- `.gt_*.json`, `.env`, `config.json` — у `.gitignore`, у репозиторій не потрапляють.
