# Ledger OS — контент-план каналу

## 1. Принципи

- **Не постимо кожен реліз.** Тільки великі оновлення, нові можливості, безпекові фікси, гайди, Q&A, опитування, кейси.
- **Максимум 1 реліз-пост на місяць.** Патчі збираємо в один дайджест раз на місяць/квартал.
- **Мова:** English → Українська → Русский в одному пості. Без прапорів.
- **Кожен пост:** 1 користь + 1 посилання/CTA + 1 питання до аудиторії.
- **Закріплений пост** — постійна інформація; змінюємо рідко (раз на квартал).

## 2. Критерії «масштабного» посту

Постимо, якщо виконано хоча б 2:
- нова велика функція (не косметика);
- зміна ціни/тарифів/ліцензування;
- безпекове виправлення, про яке має знати користувач;
- новий канал/платформа/інтеграція;
- зміна робочого процесу (наприклад, новий Taobao-агент).

Не постимо: дрібні UI-фікси, рефакторинг, внутрішні оптимізації, кожну версію 1.66.x.

## 3. Контент-піларси

| Піларс | Частка | Приклад |

## 4. Календар на місяць (4 тижні)

| Тиждень | Пост |
|---|---|
| 1 | Великий реліз або детальний розбір функції |
| 2 | Гайд / how-to |
| 3 | Q&A-дайджест (3–5 питань) |
| 4 | Опитування / кейс / behind the scenes |

Якщо релізу немає — замінюємо на гайд або Q&A. Патчі — окремий дайджест раз на місяць, не частіше.

## 5. Q&A-движок

**Звідки питання:**
- коментарі під постами;
- особисті повідомлення боту/в канал;
- повторювані питання в підтримці;
- питання з опитувань.

**Формат Q&A-посту:**
```
Q: Чи Ledger безкоштовний?
A: Так. Ledger — безкоштовний десктопний застосунок. Ledger+ — хостинг, Taobao-агент, автоімпорт і команда.

Q: Чи можна перенести ключ на інший ПК?
A: Так, через деактивацію на старому пристрої.

Що ще запитати? Пиши в коментарях.
```
Далі — той самий блок англійською та російською.

**15 вічних питань для Q&A:**
1. Ledger безкоштовний? — Так, локальний облік безкоштовний.
2. Що дає Ledger+? — Хостинг, Taobao-агент, автоімпорт, команда.
3. Чи потрібен ключ для безкоштовної версії? — Ні.
4. Як перенести ключ? — Деактивація → активація на новому пристрої.
5. Де зберігаються дані? — Локально; Ledger+ — на твоєму VPS.
6. Чи працює офлайн? — Так, дані локальні.
7. Як зробити бекап? — Settings → Backup, архіви/хмара.
8. Як імпортувати замовлення? — Gmail IMAP + Telegram-бот.
9. Що таке Taobao-агент? — Збирає лоти/ціни, потребує ПК або VPS.
10. Чи можна кілька магазинів? — Так, через канали.
11. Як рахуються комісії? — Профілі комісій по платформах.
12. Як підключити Telegram-сповіщення? — Токен бота + chat_id.
13. Як оновитися? — Новий реліз; дані залишаються.
14. Які ролі в команді? — owner / manager / viewer.
15. Чи є мобільна версія? — Браузер + QR; окремого застосунку немає.

## 6. Опитування та залучення

- «Яку функцію робити наступною?» — 3–4 варіанти.
- «Покажи свій робочий процес» — запрошення скріншотів.
- «Питання тижня» — одне питання, відповіді в коментарях.
- Не робити більше 1 опитування на 2 тижні.

## 7. Робочий процес публікації

1. Пишемо EN.
2. `python3 ledger_os_bot.py --auto --en "..." --dry-run` — дивимось UA/RU.
3. Правимо UA/RU вручну, якщо треба.
4. Публікуємо: `--post-json post.json` (або `--auto`).
5. Пін — тільки для постійної інформації, не для кожного посту.
6. Через 24–48 год — відповідаємо на коментарі, збираємо питання.

## 8. Закріплений пост

Закріплений пост містить:
- що таке Ledger і Ledger+;
- що буде в каналі (великі оновлення, гайди, Q&A);
- посилання: релізи, тарифи, бот, канал;
- правило: питання — в коментарі/бот, без спаму.

Оновлювати раз на квартал або при зміні тарифів.

## 9. Метрики

- перегляди/охоплення;
- реакції та коментарі;
- переходи за посиланнями (GitHub/pricing);
- кількість питань від аудиторії;
- підписки після Q&A/опитувань.
