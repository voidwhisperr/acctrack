# Ledger 1.66.41 — Security that holds.

Ledger 1.66.41 is a security and reliability update for the free desktop app and the hosted Ledger+ edition.

## What changed

- **2FA + step-up:** password and 2FA changes now require your current password and a one-time code.
- **Email recovery:** forgot your password? A 10-minute code is sent to your recovery email.
- **Isolated license signing:** the signing key lives on a separate host, not on the web server.
- **Encrypted offsite backups:** encrypted copies go to Cloudflare R2 and to your PC.

Your data and settings stay in place.
