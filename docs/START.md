# Як запустити й перевірити

## 1. Запуск (3 способи)

### A. Windows / ПК (найпростіше)

1. Встановіть **Python 3.11+** з [python.org](https://python.org) (галочка «Add to PATH»).
2. Розпакуйте папку з Ledger, наприклад `C:\Ledger`.
3. Двічі клікніть **`start.bat`** (у PowerShell: `.\start.bat`).
4. Відкрийте **http://127.0.0.1:8766**

У консолі побачите:

```
▲ Ledger v1.0
🔓 No password — open access (set one in ⚙ → Password)
🌐  http://localhost:8766
```

**Пароля немає.** Відкриваєте посилання — одразу працюєте.
Пароль можна увімкнути пізніше: `⚙ → PASSWORD (OPTIONAL)` → ввести (мін. 8 символів) → **Enable password**.
⚠️ Увімкніть пароль, якщо застосунок доступний з інтернету.

> Працює, лише коли ПК увімкнений. Для 24/7 — Docker або VPS.

### Доступ з телефона / інших пристроїв

За замовчуванням застосунок слухає **лише цей ПК** (`127.0.0.1`) — ніхто ззовні не зайде.

Щоб відкривати з телефона в тій самій Wi-Fi мережі:

```powershell
$env:GT_BIND="0.0.0.0"; python game_tracker.py
```

Тоді відкривайте `http://<IP-компʼютера>:8766` (адреса показується в консолі).
⚠️ У цьому режимі **обовʼязково увімкніть пароль** (`⚙ → Password`) — інакше будь-хто в мережі бачить ваші дані.

### B. Docker

```bash
docker compose up -d
# → http://localhost:8766
```

Пароль генерується при першому старті:
```bash
docker compose exec ledger cat /app/data/.gt_secrets.json
```

### C. VPS (Ubuntu, 24/7)

```bash
sudo apt update && sudo apt install -y python3 caddy
sudo mkdir -p /opt/ledger && sudo chown $USER /opt/ledger
# скопіюйте файли в /opt/ledger

sudo tee /etc/systemd/system/ledger.service >/dev/null <<'EOF'
[Unit]
Description=Ledger
After=network.target
[Service]
WorkingDirectory=/opt/ledger
ExecStart=/usr/bin/python3 /opt/ledger/game_tracker.py
Environment=GT_BIND=127.0.0.1
Environment=GT_PORT=8766
Restart=always
[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable --now ledger
```

Caddy: `your-domain.example { reverse_proxy 127.0.0.1:8766 }`

## 2. Перші 5 хвилин у застосунку

1. **Вхід** → введіть пароль (мова перемикається на екрані входу: UA / EN / RU).
2. **Онбординг** (3 кроки): мова → назва + тема → токени **або Skip**.
   Натисніть **Skip** — усе працює й без токенів.
3. **Угоди** → форма `+ Deal`: назва, платформа, купив, продав → `+ ДОДАТИ`.
4. **⚙ → Дані й діагностика → Завантажити демо-дані** — одразу побачите 20 угод і 4 акаунти на складі.
5. Перевірте: **Огляд**, **Угоди**, **Склад**, **Аналітика** — усі мають дані.

## 3. Ручний чек-лист перевірки (10 пунктів)

| # | Що зробити | Що має бути |
|---|---|---|
| 1 | Відкрити `/login` | ▲ Ledger, «Sign in», кнопка «Continue», перемикач UA/EN/RU |
| 2 | Ввести неправильний пароль | «Wrong password (401)», вхід не відбувається |
| 3 | Ввести правильний пароль | Заходьте, з'являється Онбординг |
| 4 | Пройти онбординг, змінивши назву | Назва в шапці й у вкладці браузера змінилась |
| 5 | Перемкнути 5 тем | Фон змінюється (⚙ → Тема інтерфейсу) |
| 6 | Перемкнути UA → EN → RU | Вкладки: Огляд / Overview / Обзор |
| 7 | Додати угоду: купив 4, продав 10, FunPay | У списку рядок, прибуток **+$5.85** |
| 8 | ⚙ → Демо-дані → Завантажити | 20 угод + 4 на складі, Огляд і Аналітика заповнились |
| 9 | ⚙ → Стерти дані | Списки порожні, плитки по нулях |
| 10 | ⚙ → Імпорт CSV (файл нижче) | 2 угоди додано, 1 пропущено |

Файл для пункту 10 (`test.csv`):

```csv
date,title,platform,buy,sell
2026-11-20,Arknights,FunPay,5,12
21.11.2026,Zenless,ZeusX,8,20
bad-date,Skip me,FunPay,1,2
```

Очікування: **додано 2, пропущено 1** (погана дата).

## 4. Автоматичні тести

У папці `tests/`:

```bash
# 1) запустіть застосунок в іншому вікні
python game_tracker.py

# 2) API-тести (38 перевірок)
python tests/api_smoke.py

# 3) UI-тести (потрібен Edge з --remote-debugging-port=9222)
python tests/ui_smoke.py
```

API-тести перевіряють: авторизацію, health, diag, угоди + розрахунок прибутку,
відхилення поганих даних, імпорт CSV, склад (додати/видалити), демо-дані,
постачальників (додати/валідація URL), експорти CSV/zip, аналітику, звіт,
пошту, Eldorado, налаштування (назва/мова), канали без токенів, секрети.

UI-тести: вхід і перемикання мови на екрані входу, онбординг 3 кроки,
назва застосунку, 5 тем, 3 мови, додавання угоди через форму,
усі 10 вкладок без JS-помилок, порожній каталог, склад, діагностика, контакти.

**Стан на момент релізу:** API **38/38**, UI **20/20**.

## 5. Що перевірити з токенами (опційно)

| Канал | Як перевірити |
|---|---|
| **FunPay** | ⚙ → Канали → вставити `golden_key` → «Зберегти cookie» → ↺ Оновити |
| **ZeusX** | вставити `access_token` → перевірити баланс і кількість замовлень |
| **Пошта** | ⚙ → Gmail → адреса + App Password → «Перевірити» |
| **Постачальник** | ⚙ → Мій постачальник → назва + `https://shop.example.com` → Каталог має заповнитись |

Якщо токен невірний — побачите зрозуміле повідомлення («FunPay не підключено — вставте golden_key»), а не порожній екран.

## 6. Якщо щось не працює

1. **⚙ → Дані й діагностика → ↻ Оновити** — покаже версію, кількість записів, стан токенів, розмір бази.
2. Перевірте консоль, де запущений `game_tracker.py` — там видно помилки.
3. Порт зайнятий? Запустіть з іншим: `set GT_PORT=8770 && python game_tracker.py`
4. Токен каналу прострочений → вставте новий (FunPay: F12 → Cookies → `golden_key`; ZeusX: F12 → Network → `Authorization: Bearer …`).
5. Дані зникли? `gt_backups/` містить знімки перед кожним записом, плюс `⚙ → Експорт усіх даних`.
